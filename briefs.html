01 / A&R brief

Velvet 2-Step Pop.

서로 다른 두 목소리가 가까운 거리에서 주고받는 리드미컬한 유닛곡. 첫 8초에 REI의 개성을 보여주고, LIZ가 선율의 공간을 넓힌다. 첫 공동 후렴에서 두 사람의 조합을 바로 이해하게 한다.

음악 사양

템포 / 박자
114 BPM을 우선 검토. 범위는 112-116 BPM, 박자는 4/4.
조성 후보
F# minor를 기반으로 후렴에 A major의 밝은 색을 더한다. 대안은 B minor / D major. 가이드 보컬로 편안하게 반복할 수 있는 음역을 확인한 뒤 조성을 확정한다.
벌스
F#m9 / Dmaj7 / Aadd9 / E6
프리코러스
Dmaj7 / E6 / C#m7 / F#m9
후렴
Aadd9 / E/G# / F#m9 / Dmaj7

코드는 작곡 방향을 보여주는 예시다. 그대로 따라야 하는 공식이나 필수 전조를 뜻하지 않는다.

프로덕션 사양

드럼
엇갈리는 2-step 킥, 약간 밀리는 클로즈드 하이햇, 부드러운 개러지 스네어. 벌스에는 림 클릭을 작게 넣고, 마지막 후렴의 클랩은 넓게 펼친다.
베이스
탄력 있는 서브 베이스. REI 파트에서는 짧은 엇박으로, LIZ의 프리코러스에서는 길게 유지한다.
질감
필터를 건 패드, 맑은 플럭 선율 하나, 작게 배치한 보컬 조각과 가벼운 테이프 질감.
공간
리드 보컬을 가깝게 두고 잔향은 짧게 절제한다. 자음이 들릴 공간을 확보하며, 과장된 상승 효과음이나 무거운 드롭은 피한다.

LIZ / 선율과 확장

깨끗한 리드와 긴 선율을 맡는다. 프리코러스의 더블 보컬을 좌우로 넓히고, 마지막 후렴에는 가벼운 상성부 화음과 절제한 애드리브 하나를 더한다.

REI / 질감과 훅

잔향이 적은 대화형 리드와 두 번째 벌스의 랩·노래 사이 프레이징을 맡는다. 낮은 색의 더블 보컬과 속삭이는 짧은 구절을 은은하게 더하되, 본래 목소리를 가리지 않는다.

76마디 / 114 BPM에서 2:40

아래 시간은 반올림한 값이며, 세션에서는 마디 수를 기준으로 삼는다. 112-116 BPM에서 전체 길이는 약 2:43-2:37이다.

  1. 0:004마디REI의 가까운 인트로. 드럼 전체는 아직 넣지 않는다.
  2. 0:088마디REI 벌스. 작은 2-step 하이햇이 들어온다.
  3. 0:258마디LIZ 프리코러스. 코드의 음 배치를 넓힌다.
  4. 0:428마디첫 후렴. 주고받은 뒤 처음으로 같은 구절을 부른다.
  5. 0:598마디REI 두 번째 벌스. 리듬 밀도를 높인다.
  6. 1:168마디LIZ 프리코러스. 더 긴 선율로 들어 올린다.
  7. 1:338마디두 번째 후렴. 두 목소리가 더 일찍 만난다.
  8. 1:498마디브리지. 비트를 줄이고 짧은 구절을 교환한다.
  9. 2:0616마디마지막 후렴. 같은 구절을 서로 다른 옥타브나 질감으로 부른다. 마지막 두 마디를 번갈아 맡고 2:40에 끝낸다.

후렴 작사 방향

Different taste, same side
You go left, I go right
Still we meet on the same line

“취향과 방향은 달라도 같은 선에서 만난다”는 작사 초안이다. 최종 가사가 아니며, 멤버의 관계를 따로 설명하지 않아도 후렴 자체가 이해되어야 한다.

레퍼런스에서 참고할 기능

  • IVE / Off The Record: 사적이고 우아한 분위기.
  • aespa / Thirsty: 매끄러운 보컬 레이어.
  • NMIXX / Passionfruit: 가벼운 UKG 리듬의 탄력.
  • PinkPantheress: 가까운 보컬과 짧고 간결한 전개.

청취 방향을 공유하기 위한 목록이다. 선율·코드·고유한 사운드를 가져오는 틀이 아니다.

데모 의뢰와 선정

R&B 보컬과 2-step 프로그래밍 경험이 있는 작가에게 완성형 톱라인 데모 3곡을 의뢰한다. 각 곡에는 두 목소리의 가이드, 15초 후렴 컷, 가사지, BPM·조성·마디 구성표, 작가 연락처와 지분 제안을 포함한다.

두 역할의 대비, 라이브로 부르기 쉬운 정도, 후렴의 기억성, 반복 청취 매력으로 후보를 좁힌다. 최종 선정 전에는 앉아서 부르는 보컬 확인과 동선 리허설을 진행한다.

선정 데모의 납품 기준

전체 믹스, 반주, 깨끗한 가이드 보컬과 트랙별 스템을 첫 마디부터 정렬한 24-bit / 48 kHz WAV로 납품한다. 잔향 없는 리드·더블, 화음 묶음과 샘플·기존 곡 인용 여부를 포함한다. 공연 재생본과 스트리밍 마스터는 별도로 준비한다.

타이틀곡 모방, 끼워 넣은 랩 브레이크, 무거운 드롭, 두 목소리를 같게 만드는 처리는 피한다. 조성·템포·예산은 아티스트와 제작진의 승인 후 확정한다.

02 / Music direction & session decisions

Turn the brief into a playable decision.

직접 듣고 결정하는 세션 제안. 리듬을 듣고, 움직이며 선율을 시험한 뒤, 후렴 전달을 방해하는 부분을 수정한다. 아티스트의 실제 음역·리허설 결과·완성 녹음을 제시하는 것은 아니다.

01

리듬의 탄력을 만들고, 스네어 중심은 유지한다.

114 BPM, 4/4의 한 마디를 16개 16분음표로 나눈다. 킥은 1, 2&, 3&(스텝 1, 7, 11), 부드러운 스네어는 2, 4(스텝 5, 13)에 둔다. 클로즈드 하이햇은 8분음표마다 넣는다(스텝 1, 3, 5, 7, 9, 11, 13, 15). 엇박 하이햇 4개만 18 ms 늦춘다. 전체 스윙이 아니라 해당 음의 시점만 조정하는 방식이다.

정박 하이햇은 엇박보다 작게 둔다. 대화하듯 부르는 구절 아래의 서브 베이스는 짧게, 프리코러스에서는 길게 유지한다. 보컬이 박자보다 먼저 들어오는 순간을 킥이 가리면 그 킥을 뺀다. 벌스의 림과 마지막 후렴의 클랩은 기존 리듬에 더하는 요소다.

사이트에서 듣는 오디오는 드럼·베이스·벌스 코드를 직접 합성한 4마디 스케치다. 멤버 보컬, 아티스트 녹음, 레퍼런스곡 샘플은 포함하지 않는다. 완성 데모가 아닌 리듬과 공간의 청취 예시다.

02

후렴에 관계장조의 밝은 색을 연다.

벌스는 F#m9 / Dmaj7 / Aadd9 / E6, 후렴은 Aadd9 / E/G# / F#m9 / Dmaj7. F# minor와 A major는 같은 조표를 쓴다. A로 시작하는 후렴은 더 밝은 중심을 암시하지만, 이 코드 목록만으로 전조가 확정되지는 않는다. 코드 상성부를 넓히고 베이스를 길게 유지해, 두 사람이 처음 공유하는 모음에서 확장감을 만든다.

REI는 잔향 적은 리듬형 프레이징과 짧은 응답 공간, LIZ는 긴 구절과 프리코러스의 넓은 더블 보컬을 제안한다. 두 리드는 중앙에 둔다. 상성부 화음과 옥타브는 세션에서 시험한다. 이 역할은 편곡 방향이며 측정된 음역이 아니다.

03

움직이며 부른 뒤, 편안한 반복 음역을 확정한다.

F# minor 가이드로 시작해 후렴의 각 음, 음절, 길이, 호흡 위치를 표시한다. 반복 고음과 작은 소리의 저음 진입까지 구절 전체를 시험한다. 최고음 한 번을 낼 수 있다는 사실만으로 실사용 음역을 정하지 않는다.

  1. 앉아서: 반주에 맞춰 후렴 전체를 3회 녹음한다. 보컬은 잔향 없이 받고, 재생 반주에는 보정된 리드 보컬을 넣지 않는다. 각 가수에게 힘이 드는 지점과 호흡 부담을 표시하게 한다.
  2. 움직이며: 제안한 동선을 따라 3회 더 부르고, 회차 사이에 45초 쉰다. 가이드 선율과 템포는 동일하게 유지한다.
  3. 비교: 높은 구절이 반복해서 경직되면 반음 낮춰 듣고, 낮은 진입의 명료도가 반복해서 떨어지면 반음 높여 듣는다. 후렴 전체를 다시 시험하며, 이조로 새 문제가 생기면 긴 음이나 호흡 위치를 수정한다.
  4. 승인: 동선과 함께 3회 연속 불렀을 때 선율·가사·계획한 호흡을 유지하고, 부담 호소나 계획하지 않은 옥타브 변경이 없어야 한다. 가수와 보컬 디렉터가 편안한 반복 음역에 함께 동의한다.

F# minor와 대안 B minor는 후보로 유지한다. 공개 영상만으로 최종 조성·옥타브·상성부 화음을 지정하지 않는다.

04

다시 들어 확인할 수 있는 믹스 지시를 쓴다.

수정의 출발점이다. 실제 스템에서 원인을 확인한 뒤 처리한다.
문제수정 지시통과 기준
REI의 가사가 흐려진다리드 구절의 보컬 조각을 뺀다. EQ 전에 겹치는 플럭의 음량을 낮춘다. 여전히 가려지면 보컬을 신호로 삼아 겹치는 대역만 1–3 dB 줄여 보고, 리드의 자연스러운 음색은 유지한다.모노와 작은 재생 음량에서도 같은 가사가 분명하게 들린다.
LIZ의 확장감이 약하다리드는 중앙에 두고 패드 상성부와 더블 보컬의 폭을 넓힌다. 바쁜 베이스 움직임을 줄인다. 화음을 추가하기 전에 구절 자체를 조정한다.음량을 맞춰 비교해도 프리코러스가 열리며, 리드가 거칠어지거나 화음이 과밀해지지 않는다.
킥과 서브 베이스가 뭉친다먼저 겹치는 베이스 음을 짧게 한다. 필요하면 킥에 반응해 베이스를 1–3 dB 줄이고 100–160 ms 안에 회복하는 설정으로 시작한다. 실제 음의 변화에 맞춰 시간을 조정한다.킥의 시작과 베이스의 음높이가 모두 들리고, 음량이 과하게 출렁이지 않는다.
휴대폰에서 후렴이 작아진다절제한 베이스 배음을 더하고 모노에서 리드와 더블의 균형을 다시 맞춘다. 마지막 후렴의 클랩을 확인해 자음을 가리면 줄인다.휴대폰·이어폰·리허설 재생 장비 모두에서 후렴과 베이스 리듬을 알아들을 수 있다.

한 번의 수정본에 비교 근거를 붙인다.

같은 15초 후렴의 원본과 수정본을 0.5 dB 이내로 음량을 맞춰 제공한다. 바꾼 점과 해결한 청취 조건을 적고, 스테레오·모노, 작은 음량·리허설 음량에서 확인한다. 동선 보컬 시험은 별도로 검증한다.

가사, 중심 리듬, 두 보컬의 역할이 모두 유지될 때 승인한다. 잔향 없는 보컬 기준본과 첫 마디부터 정렬한 24-bit / 48 kHz 스템을 납품한다. 공연 재생본과 스트리밍 마스터는 구분하며, 일률적인 음량 목표가 이 검토를 대신하지 않는다.

03 / Proposed wardrobe build

Two silhouettes. One stage code.

의상 도식은 SAME SIDE를 위한 자체 디자인 제안이다. 기존 화보는 두 사람의 패션 표현 범위를 참고하는 자료이며, 확정된 무대 의상이나 브랜드 협업을 뜻하지 않는다.

LIZ / 긴 아이보리 실루엣

실루엣: 허리 형태를 잡은 민소매 롱 튜닉과 비대칭 아래 패널, 몸에 맞는 무대용 쇼츠. 어깨선은 정돈하고, 두 사람이 함께 잡히는 화면에서 세로 절개가 읽히게 한다.

소재: 형태와 복원력을 확인할 중간 두께의 스트레치 캐디를 샘플로 시험한다. 몸통에는 통기성 있는 신축 안감, 쇼츠에는 색을 가깝게 맞춘 비침 없는 니트를 사용한다.

제작: 패널 연결부를 보강하고 옆 여밈을 숨긴다. 목둘레와 암홀은 바인딩 처리하며, 무선 송신기용 보강 포켓을 별도로 둔다. 실제 신발을 신고 피팅해 패널 길이를 결정한다.

REI / 짧은 잉크색 실루엣

실루엣: 반소매 크롭 라운드넥과 하이웨이스트 스코트(치마형 쇼츠). 고정한 비대칭 덧판으로 짧은 레이어를 만들고, 전체 동작에서 상의와 허리의 위치가 안정적으로 유지되게 한다.

소재: 상의는 촘촘하고 복원력이 있는 잔골지 스트레치 니트, 덧판은 무광 스트레치 수트 원단을 시험한다. 몸에 맞는 쇼츠에는 비침 없는 신축 안감을 넣는다.

제작: 목둘레와 허리밴드를 안정화하고 덧판은 봉제해 고정한다. 서로 닿는 면에서 여밈을 숨기며, 의상 겉면을 들어 올리지 않고 무선 송신기에 접근할 수 있게 한다.

공통 마감

허리에는 같은 은색 평행 바 2개를 쓴다. 모서리를 둥글게 하고 뒤에 부드러운 받침을 댄다. 크기·간격·마감을 맞추고, 공연 조명에서 눈부심이 생기면 브러시드 마감을 요청한다. 신발은 동작 시험 후 선정한 안정적인 댄스용으로 피팅한다.

헤어: LIZ는 앞머리를 고정한 매끈한 낮은 묶음, REI는 눈을 가리지 않는 짧고 정돈된 형태. 최종 세팅 전에 무선 장비와 인이어 선의 경로를 맞춘다. 메이크업: 주조명 아래 두 사람의 피부 표현을 안정적으로 맞추고 차분한 로즈 립을 사용한다. LIZ는 부드러운 눈 윤곽, REI는 조금 더 또렷한 속눈썹 라인. 리허설에서 묻어남과 땀 저항성을 확인한다.

피팅과 카메라 승인

  1. 동작: 전체 착장으로 팔 들기·스쿼트·런지·회전·마지막 후렴을 촬영한다. 가림 범위, 허리밴드 복원, 밑단 간섭, 장식의 접촉을 확인한다.
  2. 카메라: 공연 조명 아래 정면 투샷과 세로 후렴 컷을 촬영한다. 아이보리의 과노출, 니트의 모아레, 은색 반사, 넓은 화면에서 각 실루엣이 구별되는지 확인한다.
  3. 무대 투입: 스타일링·퍼포먼스 팀과 아티스트가 수정 샘플을 확인한다. 최종 조정, 송신기 접근법, 여벌 의상과 빠른 수선 물품을 기록한다.

소재·길이·신발·헤어는 동작과 카메라 확인을 통과한 뒤 확정한다. 현재 도식은 발주·공급·승인이 완료된 의상이 아니다.

04 / Proposed pilot protocol

Three signals. Two markets. One release.

첫 무대를 활동 가능성 시험으로 삼는다. 72시간 반응으로 검토를 시작하되, 그 결과만으로 발매를 자동 확정하지 않는다.

공개 전 역할과 일정

아티스트전략이 기획안·비교군·진행 및 보류 판단을 맡는다. A&R은 데모·보컬 시험·마스터 준비를 맡는다. 퍼포먼스·콘텐츠·마케팅 팀은 리허설·촬영·집계 가능 여부를 확인한다.

매니지먼트가 그룹 일정과 리허설 여력을 확인한 뒤, 서로 다른 시장의 실행 가능한 투어 접점 2곳을 확보한다. 기존 투어 날짜를 확정된 유닛 무대로 간주하지 않는다.

최소 제작 범위

곡 1개, 무대 동선 1개, LED 선 시스템 1개, 스타일링 규칙 1개. 투샷 마스터와 세로 화면에서도 잘리지 않는 앵글을 촬영한다. 리허설 배정 범위를 고정하고, 단독 MV와 전체 유닛 캠페인은 기준 통과 뒤에 검토한다.

기존 투어 제작 환경과 공식 채널 분석 자료를 이용할 수 있다는 전제다. 비교 영상의 시장별 자연 유입 시청자 수도 필요하다. 비용은 실제 업체 견적과 내부 자원 배분으로 산정한다.

  1. 공개: 미발매 특별 무대. 각자의 동선이 마지막 후렴에서 만난다.
  2. 촬영·게시: 팬의 자연스러운 발견을 거친 뒤 공식 후렴 컷 12-18초 1개를 공개한다. 발매일은 약속하지 않는다.
  3. 관찰: 공식 컷마다 게시 후 24시간·72시간에 같은 방식으로 집계한다. 7일째 두 시장을 다시 확인한다.
  4. 판단: 아티스트전략이 A&R·마케팅·매니지먼트와 수요 신호 3개를 검토한다. 근거가 빠지면 Hold(보류).

수요로 인정할 반응

01 / 후렴 재사용
원곡 후렴으로 새 퍼포먼스·노래·해석 콘텐츠를 만든 고유 창작자 수. 해당 공식 컷의 자연 유입 시청자 1,000명당 창작자로 보고한다. 창작자와 시청자를 같은 플랫폼·관찰 기간·독립적으로 확인한 시장에 배정한다. 시장별 분모가 없으면 Hold. 재게시를 중복 제거하고 공식·유료·조직적 캠페인 계정은 제외한다.
02 / 조합 키워드 성장
공개 전후, 같은 검색식·플랫폼·확인된 시장에서 LIZ + REI를 이야기하는 일별 고유 작성자 수의 평균을 비교한다. 두 기간 모두 유료·조직적 활동, 재게시만 하는 계정, 그룹만 다루는 내용, 관계성만 소비하는 내용은 제외한다. 제안곡·후렴·퍼포먼스를 명시적으로 다룬 작성자는 따로 표시해 비중을 보고한다.
03 / 발매 요청
이 곡의 스튜디오 또는 디지털 발매를 명시적으로 요청한 고유 사용자 수. 같은 시장·플랫폼·관찰 기간에서 해당 공식 컷의 자연 유입 시청자 1,000명당 사용자로 보고한다. 분모가 없으면 Hold.

비교군과 근거의 품질

공개 전에 같은 채널의 최근 공식 퍼포먼스 영상 5개를 고른다. 길이·홍보·투어 맥락이 비슷한 영상으로 비교군을 고정한다. 게시 후 같은 경과 시점에 비교하고, 최고 성과가 아닌 중앙값을 쓴다.

시청자 1,000명당 후렴 창작자와 발매 요청 사용자 수가 두 시장 모두에서 비교군 중앙값을 넘어야 한다. 반응 수인 분자와 노출 수인 분모의 플랫폼·확인된 시장·경과 기간을 일치시킨다. 이는 노출 규모를 맞춘 반응 지표이며, 실제 시청자의 전환율을 측정한 값은 아니다.

조합 언급은 공개 후 첫 72시간의 일별 작성자 평균과 공개 전 7일의 일별 평균을 비교한다. 두 시장 모두 성장해야 하며, 공개 후 집계한 유효 작성자·일의 과반이 곡을 다뤄야 한다. 계산은 일별 곡 관련 작성자 합계 / 일별 유효 조합 작성자 합계 > 50%. 각 합계에서 한 작성자는 하루에 한 번 센다. 이 과반 기준은 공개 전에 고정하는 제안 규칙이며, 자체 곡에 대한 관심을 판단 중심에 두려는 목적이다. 언급 증가와 곡 이야기가 동시에 나타났다는 이유만으로 인과관계를 확정하지 않는다.

7일째에는 공개 후 7일 전체의 조합 작성자 일평균과 곡 관련 비중을 다시 계산한다. 두 반응 지표도 7일간 노출을 분모로 다시 계산하고, 고정한 비교 영상의 같은 경과 시점과 비교한다. 수요 신호 3개가 모두 계속 통과해야 한다.

플랫폼의 시청자 지역 정보나 독립적으로 확인한 현지 채널을 사용한다. 언어만으로 시장을 정하지 않는다. 적은 표본, 누락된 분모, 불완전한 지역 정보는 통과 근거로 삼지 않는다.

Go / 발매 진행: 두 시장에서 수요 신호 3개와 근거 확인을 모두 통과하고, 아티스트·마스터·활동 일정도 승인되면 디지털 싱글을 편성한다.

Hold / 보류: 근거가 약하거나 불완전하고, 한 시장·채널만 급증하거나 그룹 활동이 반응을 이끌면 투어 무대로 유지하며 추가 관찰한다.

Build / 곡 재개발: 두 사람의 조합 관심은 높지만 후렴 재사용과 곡 발매 요청이 약하면 수정 데모를 의뢰한 뒤 파일럿을 반복한다. 현재 곡의 발매 예산은 늘리지 않는다.

발매 승인 이후

싱글과 함께 퍼포먼스 영상·비주얼라이저·녹음 비하인드·짧은 두 사람 인터뷰를 공개한다. 무대의 시각 규칙을 이어 쓴다. 파일럿 중에는 승인 범위 안에서만 자료를 준비하고, 발매일은 의사결정 이후 발표한다.

발매 28일 후 청취자당 저장, 제공되는 경우 반복 청취, 창작자 재사용의 지속, 유닛 콘텐츠 반응을 유사 발매와 비교한다. 가장 효과적이었던 편곡과 콘텐츠 형식을 IVE 그룹 활동에 돌려준다. 반복 수요와 일정 여력이 확인된 뒤에만 후속작을 의뢰한다.

수치와 기간은 제안한 작업 규칙이며 Starship 내부 기준이나 측정된 캠페인 결과가 아니다. 최종 판단은 자동 점수가 아닌 관련 팀의 공동 검토로 내린다.
