# SAME SIDE

Independent artist strategy portfolio by YOOYOUNG.

LIZ x REI original unit IP proposal.

A buildless static site: 12 scenes and a full production brief in English, covering the artist strategy, music direction, wardrobe construction and pilot criteria. Scene 03 presents full-length portraits with a separate heading and captions. Seven artist photographs, four garment-only Maison de VYNN photographs and three official-video thumbnails appear once each on the main page, and are bundled locally; image-sources.json records original image URLs and checksums. The wardrobe section uses cropped garment-only photographs and fabric details from two coordinated black-and-silver designs, with source links. Performer photographs, school-themed collections and design drawings are excluded from the wardrobe section. No generated fashion illustrations are included. Main music sections show genre, a proposed lyrical scene and linked listening references; detailed production notes and an optional synthesized four-bar Web Audio sketch live in briefs.html. The sketch contains no artist recordings or vocals.

Sources reviewed 14 October 2026. The proposed pilot respects the announced group EP Looks Can Kill and requires a separately approved rehearsal window.

This is a proposed project, not an announced artist release or an approved brand collaboration.
